Installér InstructMOS

Vælg dit værktøj, og følg de tre trin.

Trin 1 af 3

ChatGPT · Chat og Work

  1. Find InstructMOS i ChatGPT

    Log ind i browseren, og søg efter InstructMOS under Plugins. Vælg det, hvis det vises, og gå til trin 3.

    Åbn ChatGPT Plugins ↗Har du det allerede? Gå til Chat eller Work ↓

  2. Hent og upload ZIP’en

    Hvis InstructMOS mangler, og du har uploadadgang, så vælg dit workspace i Admin console. Gå til Plugins → Add → Upload plugin, og vælg ZIP-filen, som du hentede den. Hvis uploadmuligheden mangler, kan en administrator hjælpe med at gøre pluginet tilgængeligt.

    Hent InstructMOS 1.5.2 som ZIPÅbn Admin console ↗

  3. Brug det i Chat eller Work

    Start i Chat, eller skift til Work, hvis du har adgang. Skriv @ og vælg InstructMOS, eller find det under Plugins ved skrivefeltet. Prøv “Hjælp mig med at lave instruktioner til mit ChatGPT-projekt.”

    OpenAIs guide til plugins ↗

Claude Code

  1. Tilføj episMOS-kataloget

    Hvis din klient allerede er installeret, så kør kommandoen i en terminal.

    claude plugin marketplace add Mortenskj/epismos-releases

  2. Installér pluginet

    Kør denne kommando i terminalen, når kataloget er tilføjet.

    claude plugin install instructmos@epismos-releases

  3. Åbn InstructMOS i Claude Code

    Start en ny Claude Code-session. Kør denne kommando inde i sessionen.

    /instructmos:instructmos-setup

Codex

  1. Tilføj episMOS-kataloget

    Hvis din klient allerede er installeret, så kør kommandoen i en terminal.

    codex plugin marketplace add Mortenskj/epismos-releases

  2. Installér pluginet

    Kør denne kommando i terminalen, når kataloget er tilføjet.

    codex plugin add instructmos@epismos-releases

  3. Åbn InstructMOS i Codex

    Start en ny Codex-session. Skriv $ i promptfeltet, vælg instructmos-setup fra listen, og send prompten.

Gemini CLI

  1. Hent og pak ZIP’en ud

    Pak ZIP’en ud, så du får mappen instructmos.

    Hent InstructMOS 1.5.2

  2. Installér udvidelsen

    Åbn terminalen i mappen, der indeholder den udpakkede instructmos-mappe, og kør kommandoen.

    gemini extensions install ./instructmos

  3. Åbn InstructMOS i Gemini CLI

    Start en ny Gemini CLI-session, og bed Gemini om at bruge InstructMOS setup.

Fra regel til svar

Vælg, hvor reglerne skal gælde. Med pluginet kan du klargøre, tjekke og afprøve instruktioner på samme måde på tværs af projekter og AI-værktøjer.

  1. 01

    Klargør

    Vælg instruktioner til din konto, et projekt eller en kodebase.

  2. 02

    Tjek

    Sammenlign den indsatte tekst med den version, du ville bruge.

  3. 03

    Prøv

    Send en prøveprompt, og se efter én bestemt regel i svaret.

Installér InstructMOS

Vælg din klient. Du gemmer selv de instruktioner, du vælger at bruge.

Claude Code

claude plugin marketplace add Mortenskj/epismos-releases
claude plugin install instructmos@epismos-releases

Start en ny session og kør /instructmos:instructmos-setup.

Codex

codex plugin marketplace add Mortenskj/epismos-releases
codex plugin add instructmos@epismos-releases

Start en ny session og vælg InstructMOS setup i skill-vælgeren.

Gemini CLI

Pak ZIP’en ud og kør kommandoen fra mappen, der indeholder instructmos.

gemini extensions install ./instructmos

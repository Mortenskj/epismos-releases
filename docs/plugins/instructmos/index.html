Install InstructMOS

Choose the command-line tool you already use. Setting up ChatGPT, Claude or Gemini in a browser? Open the web guide.

Step 1 of 3

Claude Code

  1. Add the episMOS marketplace

    Open a terminal and run this command.

    claude plugin marketplace add Mortenskj/epismos-releases

  2. Install the plugin

    Once the marketplace is added, run this command in the same terminal.

    claude plugin install instructmos@epismos-releases

  3. Open InstructMOS in Claude Code

    Start a new Claude Code session, then run this command inside it.

    /instructmos:instructmos-setup

Codex

  1. Add the episMOS marketplace

    Open a terminal and run this command.

    codex plugin marketplace add Mortenskj/epismos-releases

  2. Install the plugin

    Once the marketplace is added, run this command in the same terminal.

    codex plugin add instructmos@epismos-releases

  3. Open InstructMOS in Codex

    Start a new Codex session. In the prompt, type $, select instructmos-setup from the list, then submit the prompt.

Gemini CLI

  1. Download and extract the ZIP

    Extract the ZIP to get the instructmos folder.

    Download InstructMOS 1.5.2

  2. Install the extension

    Open a terminal in the directory containing the extracted instructmos folder, then run this command.

    gemini extensions install ./instructmos

  3. Open InstructMOS in Gemini CLI

    Start a new Gemini CLI session and ask Gemini to use the InstructMOS setup skill.
